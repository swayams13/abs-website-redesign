- Today's date is computed client-only (`today` state starts `''`, set after mount) rather than read directly from `Date.now()` during render — since this is a statically-generated page, computing "today" during render would bake the build machine's date into the prerendered HTML and mismatch the visitor's real date on hydration (see TECH-STACK.md "Hydration"). Starting at `''` means every event compares as upcoming on both the server render and the first client paint (string comparison against `''` is always true), so there's no mismatch — it just corrects to the true upcoming/past split a moment after mount, same trade-off already accepted elsewhere on this site (`LiveStatus`, `nextBatch()`, `Locations`' open count).
- This is the first modal on the site — no existing pattern to reuse, so it was built from the design reference directly: fixed full-viewport backdrop, `z-index: 100` (above `Nav`'s 80 and the mobile action bar's 70), Escape-key listener that only attaches while a modal is open (`useEffect` scoped to `sel`, not a permanently-mounted global listener).
- No `MobileActionBar` case added for `/events` — unlike other inner pages, there's no single page-level anchor to jump to (registration happens per-event inside a modal), so it correctly falls through to the existing generic fallback ("Book a free tour" → `/#join`).
